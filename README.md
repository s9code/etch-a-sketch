# Etch-a-Sketch

Proyecto del currículo Full Stack JavaScript de [The Odin Project](https://www.theodinproject.com/).

## 🎯 Objetivo

Construir una versión web de un Etch-a-Sketch interactivo aplicando:

- Manipulación del DOM para crear y modificar elementos dinámicamente.
- Creación de una cuadrícula mediante JavaScript.
- Uso de Flexbox para organizar los elementos de la cuadrícula.
- Gestión de eventos del ratón para crear un efecto de dibujo.
- Generación de nuevas cuadrículas mediante la interacción del usuario.
- Uso de funciones para organizar y reutilizar la lógica de creación de la cuadrícula.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
